# day-piece-camera

Preview the device camera and capture still photos.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

Bind capture state and results to app signals. Configure camera permission text and handle
denial, unavailable devices, and capture errors. Desktop and browser renderers are not provided.

## Use

Add `day-piece-camera = "0.*"` to your app’s `[dependencies]`.
Build with the Day CLI to select the matching toolkit integration.
